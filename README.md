# gemeinsame-workflows

Gemeinsame GitHub-Workflows für alle Repos von martin484rudolf. Ein Repo prüft, alle nutzen es: Regeln werden einmal hier gepflegt und von jedem Repo per Aufruf eingebunden.

Herleitung und Entscheidungen: [Mistral-1#3](https://github.com/martin484rudolf/Mistral-1/issues/3).

## Grundsätze

- Dieses Repo ist öffentlich. Es enthält nur Workflows und Prüfregeln, keine personenbezogenen Angaben. Repo-spezifische Werte (z. B. der erlaubte Commit-Autor) stehen als Variable im jeweiligen Repo, nicht hier.
- Änderungen nur über Pull Request.
- Die Workflows lesen nur; sie schreiben nichts in die aufrufenden Repos.
